Inference service adds regional failover

The managed inference service now supports automatic regional failover for provisioned endpoints. Operators choose an ordered set of regions and receive an audit record whenever traffic moves.

Failover is disabled until the deployment owner opts in. Existing endpoints preserve their current behavior, quotas, and network policies, so enabling the feature is an explicit operational decision.

The update is available in three regions today. Capacity limits and recovery objectives are documented per region, and the status API reports both the active region and the most recent transition.
